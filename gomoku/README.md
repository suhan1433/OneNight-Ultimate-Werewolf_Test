# 오목 · GOMOKU

친구 또는 AI와 두는 15×15 자유 오목입니다. 흑부터 번갈아 돌 하나씩 놓고, 가로·세로·대각선으로 다섯 돌 이상을 먼저 연결하면 이깁니다. 금수는 없으며 장목도 승리합니다. 판이 가득 찰 때까지 승자가 없으면 무승부입니다.

## 플레이

- **AI와 바로 두기**를 누르면 즉시 시작합니다.
- **친구와 두기 · 방 만들기**를 누르고 방 코드나 초대 링크를 공유하세요. 상대가 입장하면 바로 시작합니다. 링크로 입장하면 방 코드가 자동으로 채워집니다.
- 내 차례에 빈 교차점을 한 번 누르면 착수하고 자동으로 차례가 넘어갑니다. 키보드로 교차점 버튼을 선택한 뒤 Enter 또는 Space를 눌러도 됩니다.
- 마지막 수는 돌 가운데 작은 점, 승리한 연결은 판 위에 강조해 표시합니다.
- 결과 화면의 **한 판 더 두기**는 양쪽이 동의하면 즉시 재대국합니다. 흑과 백이 바뀌며 AI는 자동으로 동의합니다.
- 친구와 진행 중인 대국에서 나가면 기권패이므로 한 번 확인합니다. AI전과 대기실·결과 화면은 상단 나가기 한 번으로 시작 화면에 돌아갑니다.

상점·경제·성장·스킬·특성·증강·제단·도감·연습 과제·복기·채팅·제한 시간은 없습니다. 돌 선택·미리보기·착수 확정·별도 턴 종료·준비/시작 버튼도 없습니다.

## 모바일 화면과 조작

시작·초대 대기·대국·결과 화면을 실제 보이는 화면 높이에 맞춥니다. 주소 표시줄, 안전 영역, 화면 회전을 반영하며, 320×480부터 태블릿까지 가로·세로 스크롤 없이 핵심 조작이 보이도록 검사합니다. 가로 화면은 대국자·차례·재대국 버튼을 판 옆에 배치합니다. 결과 영역은 대국 중에도 같은 공간을 예약하므로 승리 시 판이 움직이거나 작아지지 않습니다.

AI 시작·착수·AI전 나가기·AI 재대국은 각각 한 번의 조작입니다. 친구는 초대 링크에 채워진 코드로 한 번 입장하며 바로 시작합니다. 재대국은 두 사람이 각각 한 번 동의합니다. 상대가 나가면 비활성 버튼 대신 **새 대국**으로 돌아갈 수 있습니다. 안내창은 뒤의 판을 조작할 수 없게 막고 닫으면 원래 버튼으로 포커스를 돌려줍니다. 판은 Tab 한 번으로 진입한 뒤 방향키와 Enter로도 조작할 수 있습니다.

## 대국 연출

나무 결·테두리·좌표를 표현한 판과 입체적인 흑백 돌을 사용합니다. 새 착수는 돌이 내려앉는 애니메이션과 작은 파문으로 표시하고, 승리하면 다섯 돌을 따라 연결선이 그려집니다. 연출 중에도 다음 차례의 조작은 즉시 가능합니다. 재접속할 때는 이전 착수 연출을 반복하지 않습니다.

상단 스피커 버튼으로 착수·대국 종료 효과음을 켜고 끌 수 있으며 선택은 브라우저에 저장합니다. 소리는 사용자 조작 후에만 시작하고 외부 음원이나 배경음악은 사용하지 않습니다. 기기의 **동작 줄이기** 설정을 켜면 이동·파문·점멸 애니메이션을 생략합니다.

## 실행

Node.js 22 이상:

```bash
cd gomoku
npm ci
npm run dev
```

- 웹: `http://localhost:5180/gomoku/`
- 서버: `http://localhost:3011`
- 소켓: `/api/gomoku/socket`
- 상태 확인: `/api/gomoku/health` 또는 서버의 `/health`

휴대폰은 같은 Wi-Fi에서 `http://개발PC의LAN주소:5180/gomoku/`로 접속하세요. 2인 테스트에는 서로 다른 브라우저 또는 시크릿 창을 사용하세요. 같은 브라우저에서는 기존 좌석을 복구합니다.

## 검증

```bash
npm test                 # 승리·장목·무승부·유효성·AI·실제 2인 소켓·재접속·재대국
npm run build           # 타입 검사와 웹/서버 빌드
npm run test:browser     # 실제 UI에서 AI·1회 클릭·친구 초대·승리·재대국·키보드
npm run test:mobile      # 320×480~1024×768의 12개 크기에서 모든 화면과 실제 대국 검증
MOBILE_BROWSER=webkit npm run test:mobile
MOBILE_WIDTH=320 npm run test:mobile # 특정 너비의 회귀 검사
```

브라우저 검증은 빌드된 웹을 임시 서버에서 자동으로 실행하며 Playwright 브라우저 설치가 필요합니다. 화면 캡처는 `artifacts/viewport-review/`에 저장합니다. 저장소 루트에서는 `npm run test:selector`와 `npm run test:render:gomoku`로 게임 선택 및 통합 배포 경로를 검증합니다.

## 배포

```bash
npm ci
npm run build
PORT=3011 npm start
# http://localhost:3011/gomoku/
```

또는 이 폴더에서 `docker compose up --build`를 실행하세요. 루트의 `npm run build:render`는 웹을 `apps/web/dist/gomoku/`에 포함합니다. 게임 선택 화면 이름은 **오목**입니다. 기존 `/gomoku/` 및 `/api/gomoku/socket/` 경로와 포트 3011을 사용합니다. reverse proxy는 두 경로를 같은 인스턴스로 연결하고 WebSocket Upgrade를 허용해야 합니다.

방과 대국은 단일 프로세스 메모리에 저장합니다. 같은 서버가 살아 있으면 브라우저 localStorage의 비공개 세션 토큰으로 재접속합니다. 새 탭으로 복구하면 기존 탭의 연결을 대체합니다. 서버 재시작·재배포 시 대국은 초기화됩니다. 모두 연결이 끊긴 방은 30분 후 정리합니다. 제한 시간이나 자동 대리 착수는 없으며, AI는 즉시 승리·방어와 열린 연결을 평가하는 기본 휴리스틱입니다.

## 구조

- `shared/types.ts`: 오목 상태와 착수·기권 요청 타입
- `shared/engine.ts`: 15×15 판, 순수 착수 처리, 승리·무승부 판정, AI
- `server/app.ts`: 방·세션·착수 권한·동기화·재대국
- `server/index.ts`: 서버 실행과 정적 파일 제공
- `src/main.tsx`: 접속·세션 복구·요청과 화면 전환
- `src/components/`: 헤더·시작·초대 대기·대국·판·네이티브 안내창
- `src/styles.css`, `src/viewport.ts`: 가로·세로 배치와 보이는 화면 높이 반영
- `src/clipboard.ts`: 초대 링크 복사와 LAN HTTP용 대체 처리
- `src/BoardArt.tsx`, `src/assets/wood-grain.svg`: 판·좌표·시작 화면의 입체 판
- `src/feedback.ts`: 브라우저에서 합성하는 착수·종료 효과음
- `public/`: 설치 아이콘과 오프라인 연결 안내
- `tests/`: 규칙·소켓·실제 브라우저 검증
