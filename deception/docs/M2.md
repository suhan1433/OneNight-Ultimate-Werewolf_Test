# M2 구현 보고

홈 → 대기실 → 배부 → 개인 역할 → 고정 시간의 밤 → 3라운드 수사·발표 → 해결 → 목격자 반전 → 결과·재대결을 실제 Socket.IO 멀티플레이로 연결했다. 대화는 사용자 요청대로 채팅을 기본으로 한다.

## 실행

`deception`에서 `npx pnpm@10.11.0 dev` 실행 후 http://localhost:5176 에 접속한다. 4명 이상 독립 브라우저나 기기에서 준비해야 시작된다. 전체 설치·환경변수·단일 서버 배포 방법은 [README](../README.md)에 있다.

## 대기실

아발론의 `ROOM_LEAVE`, `PLAYER_KICK`, `CHAT_SEND` 처리와 로비 구조를 확인하고 같은 사용 흐름을 적용했다.

- 나가기, 도움말, 준비/취소, 방장 시작과 설정.
- 4자리 코드, 링크 복사, QR 초대.
- 방장 전용 추방. 추방된 소켓의 권한과 토큰은 즉시 무효화된다.
- 좌석 드래그 및 모바일에서 앞 좌석으로 이동. 설정 변경 시 전원 준비 해제.
- 인원 변경에 따른 기본 역할 재계산, 공범 없는 목격자 및 6인 미만 확장 역할 차단.
- 닉네임, 연결 상태, 준비 상태, 방장 표시.

| 명세/요청 | 검증 |

| 9 법의학자 연결 끊김·복귀·중단 | `M2 forensic disconnect pauses night and restores timers on resume` |

| 11 3라운드 종료 | E2E `6 users complete all three rounds without solving` |
| 11 6인 정답 | E2E `6 independent users complete a case` |
| 11 12인 반전 | E2E `12 independent users complete a case with witness reversal` |

소켓 테스트는 비인가 수사관에게 전송된 실제 `state` 패킷에 정답·비공개 역할·범인 ID·덱·RNG가 없는지 확인한다. 범행 선택 직후 비당사자에게 별도 패킷이 가지 않는지도 확인한다. 밤 종료 공통 브로드캐스트의 로컬 수신 편차가 50ms 미만인지 검사한다. 인터넷·모바일 회선에서의 지연 상한을 보증하는 검증은 아니다.

E2E는 화면에서 역할 확인·범행 선택·마커 6개 배치·채팅·해결 확정을 수행한다. 3라운드 시나리오는 R2/R3 타일 교체와 좌석순 발표를 끝까지 진행한다. 12인 시나리오는 목격자 지목으로 범인팀이 역전하며 비밀 채팅이 수사팀에 보이지 않는지 검사한다. 메모 입력 중 포커스 유지, 메모 로컬 저장과 새로고침 복귀도 포함한다.

## 남은 가정·리스크

M2와 함께 기본 비주얼·효과음·진동·메모·PWA shell을 넣었다. M3의 이벤트 전원 확인, 이론 핀, 망설임 전달, 상세 발표 기록, 전체 접근성 감사는 아직 완료로 표시하지 않는다. 선택 사항인 공용 테이블 모드와 확장 역할은 추가하지 않았다.

방과 토큰은 메모리 기반이다. 프로세스 재시작 복구와 여러 서버 운영에는 영속 저장소가 필요하다. PWA는 화면 shell을 캐시하지만 오프라인 게임 진행을 지원하지 않는다. 모바일 Safari·물리 안드로이드의 오디오·진동 및 60fps 측정은 별도 기기 검증이 필요하다. 본문 일부 문구와 캡션은 추가 i18n·접근성 정리가 필요하다.
