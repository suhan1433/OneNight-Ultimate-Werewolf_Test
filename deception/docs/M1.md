# M1 검증 보고

2026-11-08. `packages/shared`의 서버 권위 순수 규칙 엔진, 시드 RNG, 한국어 JSON 콘텐츠, 헤드리스 시뮬레이터를 구현했다. Node 테스트 77개, 타입 검사, 배포용 TypeScript 빌드가 통과했다. 스트레스 테스트 하나에서 추가로 1,080게임을 검증한다.

## 실행

`deception`에서 `npx pnpm@10.11.0 install`, `npx pnpm@10.11.0 test`, `npx pnpm@10.11.0 typecheck`, `npx pnpm@10.11.0 build`.

`npx pnpm@10.11.0 simulate 6 demo` 또는 `npx pnpm@10.11.0 simulate 12 demo`로 JSON 결과를 확인한다.

## 변경 파일

- `packages/shared/src/engine.ts`: 시간 주입 방식의 불변 상태 전이, 시도 잠금, 승패 및 반전.
- `types.ts`, `schemas.ts`, `rng.ts`: 프로토콜, 입력 검증, 직렬화 가능한 난수 상태.
- `content/ko.json`, `content.ts`: 단서 60장, 수단 60장, 장소 3종, 사인 1종, 힌트 14종, 이벤트 6종 및 검증.
- `projection.ts`: 역할별 허용 목록 방식의 정보 공개와 채팅 권한.
- `simulator.ts`, `cli.ts`, `engine.test.ts`: 시뮬레이션 및 테스트.
- 루트 및 공유 패키지의 pnpm·TypeScript 설정, lockfile.

## 공식 규칙 확인

퍼블리셔 Grey Fox Games의 [제품 페이지](https://greyfoxgames.com/collections/deception-murder-in-hong-kong-1)에서 연결하는 [공식 영문 룰북](https://cdn.shopify.com/s/files/1/0669/3961/7510/files/deception_rulebook_english.pdf?v=1699426602)과 Gen42 Games가 배포하는 [2024 영문 룰북](https://www.gen42.com/wp-content/uploads/Deception_Rules_online_EN_202402.pdf)을 확인했다.

확인한 항목: 4~12인 구성, 6인 이상 선택 역할과 목격자의 공범 의존성, 각 종류 4장 기본/3·5장 변형, 공개 법의학자, 6개 타일과 마커 이동 금지, 수사 3라운드, 좌석순 발표, 1회 해결 시도, 오답의 추가 정보 금지, 마지막 발표 즉시 종료, 목격자 반전. 카드·타일 문구와 일러스트는 전재하지 않았다. 게임을 디지털로 변환한 선택과 오리지널 이벤트의 효과는 README의 가정을 따른다.

## 검증 한계

M1에는 브라우저 화면이 없어 스크린샷은 해당하지 않는다. 봇 시뮬레이션은 공유 엔진 실행이며 실제 멀티브라우저 E2E가 아니다. projection 객체를 검증했으며 실제 WebSocket 패킷과 50ms 미만 전송 편차 측정은 서버 단계에서 별도로 검증해야 한다.
