## 3. 구조
- **씬 큐 + 상태 게이팅**: 이벤트 여러 개를 순서대로 재생하고, 재생 중에는 직전 서버 상태를 렌더링(트랙·트래커·사망·종료 화면 스포일러 방지). 재접속/첫 로드는 재생 안 함.
- **서버 필드 가정 제거**: 거부권 승인 여부는 `accepted|accept|approved` → 없으면 *트래커 증가/단계 복귀*로 추론, 지명·처형·특별선거 대상은 이벤트 필드 → 없으면 *이전/이후 상태 차이*로 추론.
- **제한 시간**: 내가 행동해야 하는 상태에서는 짧은 스탬프/포커스 장면을 생략하고 나머지를 총 2.6s로 압축(`ACT_BUDGET`). 카운트다운과 일시정지는 항상 서버 원본 `deadline/paused`를 표시.
  *서버가 `deadline`을 연출 시간만큼 늘려 주면 가장 확실합니다(권장).*
- **지목 스포트라이트**: 대통령이 고른 서류철로 **본인 화면에서만** 빛이 이동(`pick`은 서버로 전송되지 않음).
- **모바일 한 화면**: 헤더·세션 줄·원장(1줄 막대, 탭하면 펼침)·테이블(남는 높이)·트레이(흐름 안). 로그/채팅은 서랍(≡).

## 5. 아직 확인하지 못한 것
- **실제 서버와의 통합**: 서버 이벤트 순서/필드는 추론 로직으로 방어했지만 실서버 로그로 확인 필요.
- **iOS Safari / 실기기**: 검증은 Chromium 기준. `color-mix()`, `:has()`, `dvh`, `ResizeObserver` 사용 → iOS 16.4+ 필요.
- 연출 **체감 타이밍**(스탬프 임팩트, 암전 길이)과 **사운드**(합성음 placeholder)는 사람이 들어보고 조정해야 합니다.
- 카드 보드의 CSS 질감(노치, 해칭)은 아트 시트 기준으로 이식했으나 실제 인쇄/저조도 화면 비교는 안 했습니다.
