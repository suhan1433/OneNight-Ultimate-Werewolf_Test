# 연출·사운드·에셋 목록

모든 시각 요소는 코드로 작성한 SVG/CSS입니다. 실존 인물의 얼굴·실제 나치 상징·유혈 이미지는 사용하지 않았습니다. 원작 인쇄물 이미지를 추출해 재사용하지 않았습니다.

| 자산 | 위치 | 내용 |
| --- | --- | --- |
| 의원 신분증 12종 | `apps/client/src/Art.tsx` | 가상 인물 실루엣, 기자·장군·학자 등 소품 변형 |
| 자유당 문양 | `Art.tsx`의 `Emblem` | 올리브 가지와 펜 |
| 파시스트 문양 | `Emblem` | 자체 제작한 뱀과 도끼 |
| 히틀러 역할 문양 | `Emblem` | 얼굴 없는 실루엣, 서류 카드의 HITLER 표기 |
| 취조실 배경 | `styles.css` | 전구·광원·블라인드·철제 원탁·서류철·비네팅·정적 그레인 |
| 정책 타일·명패·도장 | `styles.css`, `main.tsx` | 청회색/옥스블러드, 문양·문자 함께 사용 |
| 설치 아이콘 | `public/icon.svg`, `icon-192.png`, `icon-512.png` | 자체 제작 벡터 문양과 앱 이름 |
| 글꼴 | CSS의 Google Fonts import | Noto Serif KR, Special Elite. 연결 불가 시 시스템 명조/Georgia/monospace 대체 |
| WebAudio 음향 | `Presentation.tsx` | 브라우저 합성음. 외부 음원 파일 없음 |

음향은 기본 꺼짐입니다. 사용자 클릭 후 활성화되며, 전구 험·시계·공개 이벤트의 낮은 충격음·혼란의 전신음·승리음·처형의 저음 충격을 합성합니다. 파시스트 정책 수에 따라 저음 레이어를 추가합니다. 실제 총성 녹음이나 외부 BGM을 포함하지 않았습니다.

## 상태와 표시 분리

`Presentation`은 공용 이벤트와 공용 트랙 수만 읽습니다. 개인 정책의 종류·폐기 선택은 연출·음향에 사용하지 않습니다. 서버는 화면 연출 완료를 기다리지 않습니다. 연출은 pointer-events를 차단하지 않으며 최신 공개 이벤트로 대체됩니다. 최대 4초 후 사라지고 건너뛰기 버튼으로 즉시 제거할 수 있습니다.

재접속·새 스냅샷은 기존 이벤트를 다시 재생하지 않습니다. 모션 줄이기는 OS 설정과 앱 설정을 지원하고, 저사양 옵션은 그레인과 광원 일부를 제거합니다. 강한 플래시나 주기적인 조명 깜빡임은 없습니다.
