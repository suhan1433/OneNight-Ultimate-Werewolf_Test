# 테스트 보고서

검증일: 2026-11-16. Node.js 22.16.0, macOS ARM64. 제공된 공식 PDF와 사용자 승인 재셔플 기준을 적용했습니다.

## 규칙·불변식

`tests/engine.test.ts`의 규칙 테스트 20개 통과:

- 인원별 배분·밤 정보·초기 비밀 정보 필터링
- 생존자 수에 따른 임기 제한, 동수 부결, 사망자 정족수 제외
- 가결 시 트래커 유지·정책 제정 시 초기화
- 혼란·거부권 승인/거절·다섯 번째 파시스트 정책의 거부권 해금
- 인원별 권한 표, 조사 결과 범위·재조사 금지, 엿보기 순서
- 특별 선거의 부결·입법 종료·거부권 승인 후 순서 복귀, 사망자 건너뛰기
- 히틀러 조기 수상, 3정책 이후 히틀러 아님 표식, 네 가지 승리 조건
- 처형 후 입력·발언 제한, 진행 중 관전 비밀 정보 제한
- 입법·혼란 직후 재셔플, 혼란 정책 승리 판정
- 불법 입력의 원본 불변성, 내부 세션 필드 허용 목록 필터링

`tests/simulation.test.ts`의 고정 시드 무작위 **20,000판** 통과. 5~10인 구성 순환, 투표 부결·거부권 요청을 포함합니다.

## 실제 서버 통합·보안

`tests/server.test.ts`의 통합 테스트 5개 통과:

1. 실제 5인 Socket.IO 연결, 준비·게임 시작, 개인 페이로드 확인, 관전 제한, 중복 명령, 오래된 상태 거절, 재접속, 잘못된 토큰, 봇 대체, 게임 완주 및 종료 상태 복구.
2. 손상된 입력과 IP별 방 코드 시도 제한.
3. 5·6·7·8·9·10인 **6개 방, 총 45석** 동시 완주와 방 간 격리. 각 방은 실제 호스트 연결 1개와 나머지 봇으로 구성.
4. 진행 중 재시작의 일시정지/재접속, 잘린 저널 마지막 줄 제거 및 이후 재복구.
5. 전원 이탈 후 먼저 돌아온 참가자에게 의장 권한 이전, 연결 끊긴 참가자의 봇 대체 및 재개.

기록된 한 부하 실행: 약 3.5초, 호스트 액션 78건, 응답 P95 76ms. 로컬 디스크·개발 기기·빠른 봇 설정에서 측정한 작은 부하 점검입니다. 수백·수천 명 운영 용량이나 인터넷 지연을 보장하지 않습니다.

## 실제 브라우저

Playwright Chromium 데스크톱(1440×1050) 및 모바일(390×844) 테스트 2개 통과:

- 홈 → 대기실 → 봇 추가 → 준비 → 시작 → 역할 열람 → 표결/입법/권한 → 결과.
- 결과 화면 새로고침 시 복구, 역할 전원 공개.
- 손 떼기/키보드 키 떼기로 역할 봉인.
- 규칙·크레딧 모달, 모바일 가로 넘침 없음.
- PWA manifest 및 서비스 워커 제어 확인.
- 데스크톱 전체 플레이 중 JavaScript 페이지 오류 없음.

화면: `screenshots/home-desktop.png`, `home-mobile.png`, `lobby-desktop.png`, `board-desktop.png`, `board-mobile.png`, `result-desktop.png`.

## 빌드와 검증 범위

`npm run typecheck`, `npm run build` 통과. 웹 빌드 JS 약 236KB / gzip 약 77KB. 네이티브 앱은 Capacitor 설정과 플랫폼 의존성까지 포함하며 실제 기기·서명·앱스토어 배포·IPA/APK 생성은 미실시했습니다. Safari/Firefox·스크린리더·모바일 기기의 60fps·음향 품질은 수동 검증 대상입니다. Docker 이미지 빌드·일반 사용자 실행·헬스 체크·실제 5클라이언트 게임 완주·브라우저 동일 출처 방 생성을 검증했습니다.
