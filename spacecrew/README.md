# 더 크루: 행성 9 탐사 — 온라인

참고 HTML의 협력 트릭테이킹 규칙을 각 기기에서 접속하는 실시간 방 코드 게임으로 바꾼 버전입니다.

```bash
cd spacecrew
npm install
npm run dev
```

React/Vite 웹 앱은 `http://localhost:5177`에서, Socket.IO 게임 서버는 `http://localhost:3005`에서 실행됩니다. 같은 Wi-Fi의 휴대폰에서는 `localhost` 대신 실행 중인 PC의 LAN IP와 `:5177`을 사용하세요.

프로덕션 정적 앱은 `npm run build`로 `../apps/web/dist/spacecrew/`에 생성됩니다. UI는 `src/main.tsx`, 스타일은 `src/styles.css`, 서버 판정은 `server.mjs`에 있습니다.

## 룰북 대조 및 검증

동봉된 `스페쿠_룰북.pdf`와 `스페쿠_미션룰북.pdf`를 기준으로 50개 미션의 과제 수, 순서 토큰, 통신 제한, 특수 목표와 5인 과제 전달 규칙을 점검했습니다. 확인하여 수정한 항목은 다음과 같습니다.

- **대상 지정 정보**: 5단계 선택 버튼에 `이름 · 좋음/나쁨/응답 대기`를 표시합니다. 다른 대상 지정·커맨더 분배 미션도 각 승무원의 응답을 표시합니다.
- **커맨더 분배**: 24·32·36·43단계에서 커맨더가 끝까지 배정합니다. 현재 과제만 공개하며, 과제마다 응답을 다시 받습니다. 균등 분배가 불가능해지는 선택은 화면과 서버 모두에서 차단합니다. (기본 룰북 PDF 18쪽)
- **이웃 방향**: 12단계는 오른쪽 승무원에게서 무작위 카드 한 장을 가져오고, 46단계는 분홍 9 소유자의 왼쪽 승무원이 담당합니다. 분홍 9 소유자와 담당자를 승무원 현황에 표시합니다. (미션 룰북 PDF 4·10쪽)
- **순서 및 종료 판정**: 번호 과제와 나머지 과제를 같은 트릭에서 조건에 맞게 완료해도 실패하지 않습니다. 17·13·44·46단계는 목표를 완료하면 성공 처리합니다. 아픈 승무원·정확히 한 번 승리 등 전체 진행을 확인해야 하는 미션은 끝까지 판정합니다. (기본 룰북 PDF 10·14~16쪽)
- **재도전·통신·마지막 트릭**: 33단계 승리 횟수를 초기화하고, 이미 낸 통신 카드는 사용 완료로 표시합니다. 성공·실패로 끝나는 마지막 트릭도 공개 연출과 결과에 반영합니다.
- **테스트 봇**: 커맨더 분배와 조난 신호의 방향 합의·동시 카드 전달에 사람과 같은 진행 규칙을 적용합니다.

```bash
npm test
npm run build
```

`server.test.mjs`는 3·4·5인별 50개 미션 초기 설정과 오류 재현, 잘못된 선택 거부, 실제 Socket.IO 클라이언트의 응답 전달 및 연속 배정을 검증합니다. 데스크톱과 모바일 화면에서 5단계 상태 표시·대상 선택 및 커맨더 연속 배정도 확인했습니다. 전체 50개 미션을 사람이 끝까지 플레이한 검증은 포함하지 않습니다.
